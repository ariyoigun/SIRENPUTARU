Pengaturan & Cek Koneksi Database

Konfigurasi koneksi MySQL Server langsung ke database hostinger siren.satuputarudemak.id dan unduh file SQL untuk phpMyAdmin.

Panduan Impor phpMyAdmin

  1. Klik tombol hijau Unduh database_siren.sql di atas.
  2. Buka cPanel / Hostinger Panel dan pilih menu phpMyAdmin.
  3. Pilih database u490770675_siren pada daftar database di sisi kiri.
  4. Klik tab Import di bagian atas phpMyAdmin.
  5. Pilih file database_siren.sql yang telah Anda unduh, lalu klik Go / Kirim.
  6. Semua tabel (users, pekerjaan, cms, kecamatan) beserta 230+ data perencanaan akan otomatis tercipta.
Catatan Sinkronisasi: Sistem SIREN mengadopsi Dual-Storage. Setiap kali Anda menambah, mengedit, atau menghapus pekerjaan di website, perubahannya langsung dieksekusi dan disimpan permanen di database MySQL.
